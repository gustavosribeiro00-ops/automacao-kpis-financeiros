# Dashboard de KPIs Financeiros por Filial 📈

Pipeline em Python e Pandas para consolidação de receitas, custos e margem operacional por unidade de negócio.

## 🚀 Funcionalidades
* **Engenharia de Indicadores:** Cálculo de Lucro Líquido e Margem de Lucro Percentual por filial.
* **Consolidação Executiva:** Sumarização da Receita Total, Lucro Total e Margem Média Operacional.
* **Exportação Automática:** Geração da base consolidada em `relatorio_kpis.csv`[cite: 2].

## 🛠️ Tecnologias
* Python 3
* Pandas
* Git & GitHub (Remote-First Workflow)[cite: 2]
